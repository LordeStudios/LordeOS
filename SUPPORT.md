# Support

## Where to ask

- Questions and usage help: the [issue tracker](https://github.com/LordeStudios/LordeOS/issues). Please search before opening a new issue.
- Bug reports: [open an issue](https://github.com/LordeStudios/LordeOS/issues/new) and include the details listed below.
- Feature requests: the same issue tracker.

## What to include

- Lorde OS version, shown in Settings, About.
- Android version and device model.
- Whether you installed the full build or the companion build.
- The relevant part of the activity log or the exact steps to reproduce.

Please do not post personal data, pairing codes, API keys or license keys in public issues.

## Before filing a report

1. Check the [README](README.md) for requirements and known limitations.
2. Confirm the checksum of the APK you installed against the release page.
3. For a missing update notice, make sure Settings, Recovery, Check for updates can reach `api.github.com` from the device.
